★照搬留档（quirk 原样）：

- **未移植**：`className`/`style`（Dart 侧外层包裹）、`motion` 传函数/对象（仅 bool）、`onChange` 的事件对象（只有有序 keys 回调）、`Collapse` 上的 `data-*` 透传、Collapsible 的 `collapseHeight`/`collapseHeightAdaptive`/`fade`/SSR id（`aria-owns` 关系由 Flutter 语义树承担，未建 id 关联）。

## collapsible（docs/semi_collapsible.md · 差异清单）

照搬留档（quirk 原样）：

1. **onMotionEnd 双向触发**：展开、收起动画结束都回调（上游 timer/transitionend 语义——区别于 SemiCollapse 面板回调仅收起触发的口径）。
2. **collapseHeight 非 adaptive 可高于内容**：收起态恒为 `collapseHeight`，内容矮时留空（上游 `height: collapseHeight` 语义）。
3. **opacity 公式照搬**：`fade` 仅 `collapseHeight == 0` 生效（上游 `(isOpen || !fade || collapseHeight !== 0) ? 1 : 0`，index.tsx:208）。

偏差/裁剪：

4. **同步测高取代 ResizeObserver**：上游 ResizeObserver + `Math.ceil` 测内容高、`reCalcKey` 触发重测（index.tsx:97-116/:145-158）→ 移植在布局期同步量高，内容尺寸变化天然跟随（比重测窗口更稳）；`reCalcKey` 保留仅触发重建。
5. **unmeasured 窗口不复存在**：上游首测前 `height: 'auto'` + `maxHeight` 夹取（unmeasuredCollapsed，index.tsx:200-207）→ 同步布局无未测窗口，该分支不复刻。
6. **曲线双向同形近似**：上游 CSS transition 插值 `from + (to - from) * C(progress)` 对收起方向镜像曲线；移植按 open-fraction 统一 `curve.transform`（SemiCollapse 移植同口径），中断续播亦以控制器值连续过渡。
7. **fade 透明度进度化**：上游 opacity 是目标值 + CSS transition；移植按 open-fraction 连续插值 `Curves.easeIn.transform(t)`（静止态与瞬切一致）。
8. **瞬切便利扩展**：`TickerMode` 关闭 / `MediaQuery.disableAnimations` 时瞬切且不回调（上游仅 `motion` 开关）。
9. **duration 类型**：上游 `duration: number`（毫秒）→ `Duration?`（null 取主题）。
10. **className/style/id 裁剪**：`className`/`style`/`getDataAttr` 不移植（Flutter 无 CSS 类）；`id`（上游 wrapper 元素 id，配合 `aria-controls` 建立控制关系）不移植——由 Flutter 语义树承担关联。
11. **无障碍**：收起内容不摘语义/焦点（与上游 `overflow: hidden` + `height: 0` 的可达性一致——上游亦无 `aria-hidden`）；需要隐藏时由使用方自行包裹 `ExcludeSemantics`。
12. **上游 FAQ 不复刻**：父级 `display: none` 无法测高的问题（content/show/collapsible/index.md FAQ）在同步布局模型下不存在对应分支。

## color_picker（docs/semi_color_picker.md · 差异清单）

1. **值模型折叠**：上游 `ColorValue` 存 `{hsva, rgba, hex}` 三份（hex 保留输入原文、rgba/hsva 的 alpha 可按路径分叉）；本移植折叠为 `SemiColorValue{h,s,v,a}` + 计算通道（r/g/b = `hsvaToRgba` 取整、hex = `rgbaToHex` 规范输出）。后果：①★hex 恒小写规范形（用户输入的 `#AABBCC` 重同步后变 `#aabbcc`，上游保留原文）；②★RGB↔HSV 整数取整有损，(57,197,187)（`#39c5bb`）回程得 g=196（`#39c4bb`）——默认品牌值 `SemiColorValue(h: 176, s: 71, v: 77, a: 1)` 是 `#39c5bb` 的取整 hsva（`parse('#39c5bb')` 与默认值相等），但计算 hex 为 `#39c4bb`；③rgba/hsva 逗号输入 >2 位小数的 alpha：上游 hsva 路径的 rgba.a 先 `round(a, 2)` 再入 hex、rgba 路径不取整——本移植统一按 `rgbaAlpha = round(a, 2)` 进 hex/色块/% 显示（1/255 级误差）。
2. **NaN 坍缩**：★`hexToRgba` 上游对垃圾分量产出 NaN（如 3 位简写）；Dart 数值管线不容 NaN，解析边界坍缩为 0（宽松性保留：不抛错、缺 alpha=1）。
3. **alpha=false 归一位置**：★上游 handleChangeA 的 `!alpha → a=1` 在 alpha=false 时不可达（UI 隐藏），本移植提升为提交级归一（契约项 7）。
4. **eyeDropper 宿主桥**：WICG EyeDropper 无 Flutter 通道 → `onEyeDropper: Future<Object?>? Function()?` 回调桥（返回 hex/`rgba(…)` 字符串或 `SemiColorValue`）；★rgba 结果强制 a=1、失败/hsv/垃圾静默忽略（上游 try/catch）。
5. **格式 Select 用 SemiSelect**（nested overlay 的 SemiOverlayPointerExempt 机制覆盖）；上游 `optionList` → `options: SemiSelectOption(value: name)`（labels = values）。
6. **`%` 输入用 SemiInputNumber**（`hideButtons: true` + `%` 后缀槽）对位上游 `InputNumber hideButtons` + suffix span；宽度 58px 走主题字段。
7. **InputGroup 连体边框未移植**：上游输入组（Input + InputNumber + Select）有 InputGroup 连接样式，本移植为普通 Row（各控件自带边框）。
8. **`className`/`style`/`inputProps`/`popoverProps` 不移植**（粒度裁剪）：`position`/`autoAdjustOverflow`/`motion` 直接参数化；弹层无 `repositionKey`（hover 弹层尺寸恒定）。★弹层白底：上游由 Popover 组件自带表面渲染，本移植 popupBare 模式自绘同款皮肤（B 表末行）。
9. **把手位置微差**：受控不回吐时上游把手停在原始指针点（未量化），本移植统一停在量化值点（≤1px）；无视觉可感差异。
10. **无键盘/RTL/Form**：上游即无（仅 SemiInput/SemiSelect/SemiInputNumber 自带）；滑条数学 LTR-only，RTL 未适配（note）。

## descriptions（docs/semi_descriptions.md · 差异清单）

- 上游 `data`/`children`（`Descriptions.Item` JSX 形式）在此统一为 `items`（`SemiDescriptionsItemData`）。

## scroll_list（docs/semi_scroll_list.md · 差异清单）

★照搬留档（quirk 原样）：
1. **normal 不去重**：`this.foundation.selectIndex(index, this.list)` 即点即通知——重复点同一行仍发 onSelect（wheel 才走去重双门）。
2. **transform 门 = `selectedIndex === index` 严格相等**：越界 selectedIndex 无行命中（高亮/transform 同门）；cycled 时该数据项全副本均过 transform（上游 renderItemList 同）。
3. **wheel 定选亮虚拟节点**：`semi-scrolllist-item-selected` 只落定选副本（上游节点语义）——cycled 同数据项多副本不全亮。
4. **hover/active 门内排除选中/禁用**（`:not(.disabled):not(.-item-disabled):not(.-item-sel):not(.-item-selected)`）——wheel 定选行不出 hover/active 底色但保留 `cursor: pointer`。
5. **wheel `!important` 主色**：定选字色为样式内联 `var(--semi-color-primary)`（变量外）——消费走 `theme.colors.colorPrimary`。
6. **`$width-scrollList_item_wheel-border` quirk**：scrollList.scss:125 滚轮分隔写 `$border-thickness-control`（同值 1）——本移植 wheel 分隔消费本变量（净效果一致）。
7. **JS String() 语义**：value 出文案整数值不带 `.0`（badge `_formatNum` 先例）。
8. **wheel mount 发一次 onSelect 初值**：mount 滚动事件 → `debouncedSelect` 落选，foundation `_cachedSelectedNode` 初值 null 去重门放行 → 33ms 后通知一次初值（受控父级回写同值无感）；normal 不发（上游无 onScroll 链）。

偏差/裁剪：
9. **cycled 虚拟循环列表**：上游 prepend/append DOM 副本 + `initWheelList`/`adjustInfiniteList` 滚中搬移（`const ratio = 1;` 调平）→ 本移植固定虚拟块数 + 静默 re-wrap（无限滚动、轮回下标、同副本去重净效果一致；不搬 DOM 节点）。
10. **吸附/滚动动画**：上游 120ms `animatedScrollTo`（semi-animation）→ `animateTo(120ms, Curves.easeOut)`；`motion` 函数形态收敛为 `bool`（true 动画/false jumpTo）。
11. **onSelect 载荷**：`{...item, value, type, index}` → `SemiScrollItemSelection({item, index, type})`（item 携 value/text/disabled/transform）。
12. **`aria-label` → `semanticsLabel`**、`aria-selected`/`aria-disabled` → `Semantics(selected/enabled)`（`node.setAttribute('aria-selected', String(node === selectedNode))` 语义等价）。
13. **selectedIndex 越界收敛 clamp、负值收 0**（上游 `selectedIndex > -1 ? selectedIndex : 0` 仅 mount 收负值，越界 mount 会崩——本移植收敛为可用区间，差异注明）。
14. **根尺寸**：`width: 100%` → 随父约束满宽（`SizedBox(width: double.infinity)`——父级无界时需自定宽）；`height: 100%` → 随内容（body 300 + header/footer）。
15. **`$color-scrollList_selected_item-icon`/`$width-scrollList_item_sel_svg`/`$spacing-scrollList_item_sel_svg-marginRight`**：上游 `-item-sel > svg` 图标槽（SVG 子 16×16 + margin-right）不可达（`{text}` 渲染恒 string）——字段留档不消费，不渲染图标槽。
16. **`ul:before` 高度公式**（`($height-scrollList - $height-scrollList_item) * 0.5`）与 `$spacing-scrollList_item_ul-paddingBottom` 同值 132——首尾留白块共用后者（B 表留档公式原文）。

## select（docs/semi_select.md · 差异清单）

- **选中键 label → value**：上游 `selections` Map 以 `option.label` 为键（同 label 异 value 会互相顶替）；本移植以 `value` 为键（toggle/去重/Backspace 均按 value）。placeholder 项 `{value, label: value.toString()}` 语义同上游 `_notExist`。
- **onChanged 联合承载**：上游 `onChange`（值）+ `onChangeWithObject`（对象）双通道；本移植 `onChanged` 只发值（单选 `Object?`、多选 `List<Object>`），对象经 onSelect/onDeselect 携带，`onChangeWithObject` 不移植。diff 门控在多选同样生效（上游 `_diffSelections` 多选恒真、每次 toggle 都发）。

- **triggerRender/virtualize/ellipsisTrigger/inputProps/onChangeWithObject 不移植**：triggerRender（自定义触发框内容）、虚拟滚动（virtualize）、宽度溢出折叠（ellipsisTrigger/OverflowList，只保留计数折叠 maxTagCount）、inputProps（内嵌 Input 透传）、onChangeWithObject。
